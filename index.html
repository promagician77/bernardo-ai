And it has to be the same coat six times. Not a plausible black quilted coat six times. The same chevron count, the same direction change, the same channel widths, front, side and back. That is what image generation cannot promise, because it samples a distribution rather than reproducing an object. There is no prompt, seed or reference weight that turns "plausible" into "identical".

You already know this. It is why you wrote:

"AI-generated imagery must preserve these details and accurately represent the actual product. We do not want AI 'reinterpreting' the garment."

The only reliable answer is to never let the model draw the garment. Anyone answering your question 5 with prompt technique, LoRAs or reference weighting is describing how to make reinterpretation less likely. That is a different promise from the one you asked for.

So the garment is preserved, not generated

How models stay consistent

  • Identity from a locked reference set, never a text description
  • Pose from an approved library stored as pose maps, reused not re-prompted
  • Light and background plated to the measured spec
  • Seeds, versions and parameters recorded per image, so a frame can be regenerated a season later

That last one is what makes it a system. A model you cannot reproduce in March is not a Bernardo digital model; it is an image you liked once.

Retouching

Yes, every frame, by hand, in Photoshop. Garment edge at the composite, contact shadow, hem and cuff fall, hardware highlights, hair against the background, then a set-level colour pass so six frames match each other rather than individually matching a spec. Generated output is the middle of the process, not the end of it.

The test project

You proposed one or two products. I would do one, properly, at six images, because six is where consistency actually gets tested. Any method produces one good frame.

The drop is the whole argument. The first product pays for casting the model, locking the light and writing the spec. Everything after reuses them. If the test works, the second product should cost about half, and that drop is the thing to judge rather than the first result.

What ships with the test

  • One SKU, six final images at 2400×3600, named to your convention
  • Side by side with your existing shots of the same SKU, so the comparison is honest and immediate
  • The written spec, extended with whatever the test teaches
  • The checker, run on every delivered frame, output included
  • A written note on what the method could not do and which frames still need a camera

What I would need

  • The SKU's full existing shot set at master resolution. The plates come from these.
  • Flat or mannequin shots if they exist. Better plates than on-body.
  • Two or three retouched masters, so retouching standards are matched rather than guessed.
  • Which aspect standard this SKU ships to.
